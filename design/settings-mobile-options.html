Settings on phone: what's wrong and three ways to fix it

I checked your five screenshots against the Settings CSS (styles.css, the @media (max-width:720px) block) and against the modal style from PR #69 (header bar, grouped list box, grey footer bar with the main action). All three options below use those same pieces. They differ only in how you move between sections. The fixes to the content inside each section are the same in every option.

What's off today

  1. The section picker is a native <select>, so Android opens its own dark radio list. That list is the only dark surface in a light app, and it has no icons and no grouping style. It's also the screen with the heaviest focus ring: a 2.5px navy outline around a bordered box.
  2. The header uses about 40% of the screen before any content. The full-size "+ Add engineer" button squeezes the title and hint into a narrow column that wraps onto 4 lines. Below that come a separate picker band and then another hint paragraph.
  3. Engineer, board and user cards use the desktop table, stacked. Each card is a label/value row with a lot of empty space, a lone × floating in the corner, and a "—" for an empty phone. One engineer fills most of the screen.
  4. The Non-working days control wraps, so Sat drops onto a second row.
  5. The Users tools wrap onto three lines: a half-width search, Role/Status buttons, and Excel on its own row. The name chip with a dash looks broken.
  6. The footer bar has no Save button. The status text sits alone, and below it a strip of the board's green gradient shows, so the page stops short of the screen's bottom edge.

Shared fixes (in all three options)

  • Header = the modal header band: back chevron, title, a one-line hint, and an icon-only + on the right. The long hint moves into a collapsible "About" note or the edit sheet.
  • Lists = the grouped list box from Hide/Unhide and Add Mission: one row per item, about 56px tall, colour swatch + name + role chip + phone, and a chevron. Tapping a row opens an edit sheet (the side-panel form, shown as a bottom sheet on phone). Remove moves into that sheet as a red text action, so it can't be hit by accident.
  • Footer = the modal footer: "2 unsaved changes" on the left and Save on the right. A changed row gets an amber edge, the same as desktop. The footer fills to the bottom edge, so the green gap goes away.
  • Weekdays become a 7-across segmented control (S M T W T F S). Users get a full-width search, a scrolling row of filter chips with counts (like Hide missions), and Excel as an icon button in the header.

Option A · Settings home list → section page My pick

The avatar menu's "Settings" opens a home list grouped as Personal / Board setup / Administration, with an icon and a count on each row, like the phone's own Settings app. Tapping a row slides in that section with a back chevron. There is no picker at all, and every section gets the full screen. The section's back chevron returns to the list, and the list's × returns to the board.
