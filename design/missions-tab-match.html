Missions tab, matched to Manpower and Host

The Missions tab was built beside the others and still looks like a different app. This page shows what changes, side by side with how it looks now. Nothing is built yet; the change list says what each number below points at.

What feels off today

  • The toolbar sits about 5px lower than the other tabs. The Open / Closed / All switch is 36px tall beside 32px buttons, search is shorter, Board is a browser dropdown, and Bulk edit is on the row below Export.
  • The stat tiles have grey dots and no bar. Manpower and Host colour each tile, add a split bar and a chip row.
  • Fifteen green pills and a blue Close… link repeat down the table. The other tables stay quiet and keep colour for what needs a look.
  • Night is a purple pill, Status is a pill, and every row shows its actions.

What changes

  • 1Same toolbar as Manpower: a 330px search, Open / Closed / All and one Filters button on the left; Bulk edit and Export together on the right. Every control is 32px tall and the switch is no longer taller than its neighbours. The Board dropdown goes away.
  • 2Tiles split Total by where each mission is now, with a colour dot each and a bar under them. Missions with no crew become an amber chip on the right, like Host's "without a location".
  • 3"By board" chips replace the dropdown. They filter like Host's "By area" chips, and you can pick more than one.
  • 4Status is a colour dot and a word. Pills stay only for alerts.
  • 5Row actions appear on hover, like Host's edit pencil. Add to board stays on the rows that need it.
