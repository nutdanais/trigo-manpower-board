Calibration planner, with a spread assistant inside

One page behind the dashboard card's "All ›". It lists every tool due, and a single button turns the same page into the spread assistant, which evens out the due dates so tools stay available to engineers. Both edit the same planned dates.

Sample data, as in the options page. Everything below is live: try the card, then the planner.

How A and B fit together

One page, two modes

List is the planner: every tool, grouped by week, with Move earlier on each row. Spread is the assistant, on the same page and the same chart.

One set of planned dates

A move from either mode sets the same planned date. Tools that are already planned, or placed by hand, stay put when the assistant runs.

One weekly target

The target above the chart is the most calibrations you want in a week, so tools stay available. It is a goal, not a lab limit. It drives the amber bars, the suggested weeks and the assistant.

One spread, then it holds

A tool pulled forward is calibrated once, early, up to 3 months. Its next due date is that date plus its interval, so next year stays spread out without more moves.

Ways in from the dashboard

Each one opens the planner in a different state. Switch the range, click a bar, press All, or press Spread in the alert.

After the card changes

The card reads the same planned dates, so it updates when moves are planned.

The planner

Try it: press Spread…, click the bar for the week of 29 Mar, move one tool by hand, then Plan the calibrations. You return to the list with a planned date on each tool, and Undo is one click.

Dashboard › Tools › Calibration planner

Each tool goes to the nearest earlier week at or below the target, and two of the same type avoid the same week where they can. Nothing moves past its due date. Tools already planned or placed by hand stay where they are.

What the build needs

Data

  • A planned calibration date on each tool, separate from the due date.
  • A weekly target setting (not a hard limit) and an early window setting, up to 3 months.
  • A short log of moves: who, when, from which week.
  • When a calibration is done: next due = date done + interval.

Build in this order

  • 1. Card changes and the List mode, read-only. This already answers "see in detail".
  • 2. Move earlier on a row, with the planned date.
  • 3. Spread mode: the rules, the preview and Plan.
  • 4. Move by hand inside Spread, and Undo.

On a phone

  • List: the chart on top, then the list as cards instead of a table.
  • Spread: the rules in a sheet, the preview on top, moves below.
  • Hover details become taps. Everything else stays the same.

Decided

  • No lab limit. The weekly target only keeps tools evenly available to engineers.
  • A tool may be calibrated up to 3 months early, as a one-time spread.
  • After that, each tool's next due date follows its new calibration date.

Still to confirm

  • Should the assistant keep at least one tool of each type in service? The "Spread each tool type" option is a first version of that.
  • Who is allowed to plan moves, and who approves them?
  • Are any tools left out of spreading, such as critical ones?
