Mobile redesign — directions

The board was built for a desktop with a mouse: a two-row navy header, a five-tab strip that scrolls sideways, a toolbar that hides under ⋯ More, a floating employee pool, and side-panel modals. On a phone that leaves roughly a third of the screen for the actual missions. This page audits what's there today, then shows four directions as phone mockups. Pick one (or mix parts). Shared component changes that apply to all four are at the bottom.

B · Week strip + centre action button

B

Date as a swipeable week, pool as a pull-up drawer

Best for daily planners

Built around how planners actually work: change the day, look at who's free, place them. The top bar shows a week strip (a dot marks forecast days). C · Light surfaces, large titles

Shared component changes (any direction)

Buttons

44px minimum height on touch (today 32–40px). One green main action per screen; navy for structural confirms; outline for secondary; text style for tertiary. Press = scale(.97). Destructive actions are outline only and never sit next to the main action.

Chips

All 18Short 2Contract: Permanent ×Night

Replace the "Contract: All / Position: All…" dropdown stack with a Filter chip that opens a sheet, plus a row of active-filter chips with × to remove each. Counts use tabular numbers. Leave tabs become chips: short label + count ("Annual 3").

Modals → sheets

Pick / confirm → bottom sheetLong form → full screenDiscard? → small dialog

Bottom sheets with a grab handle for pickers (board, filters, create, add people). Full-screen for Mission, Employee, Host, User, with Save pinned to the bottom and kept above the keyboard (visualViewport). Close on the left (×/‹), the one secondary action on the right. Keep the existing unsaved-changes guard.

Top bar

Board ▾DateMode pillAvatar

Max 52px, one line. Logo and "Operations Planning" hidden on phones (keep them on the splash and export). Save status becomes a small dot on the avatar. Lock, Settings, Export, Sign out move to More / account.

Bottom bar

4–5 itemsIcon + label alwaysBadge for alerts

Shown only ≤640px; desktop keeps today's header tabs. Respect env(safe-area-inset-bottom). Items follow permissions (can()) — if a user has fewer than 3 modules, hide the bar. The "holds taken from you" alert becomes a badge on More.

Undo & Reset

Undo → toast after each changeReset board → More, with confirm

Removes the Undo/Reset pair from the toolbar on phones. Remove "Ctrl-click" and "double-click to rename" hints on touch; rename moves to a menu item.

Pick a direction

My recommendation: A as the base (bottom bar, 1-line top bar, sheets, chip filters) + D's mission-first "+ Add" sheet + B's pool drawer for planners. That fixes the biggest problems (header height, hidden modules, scroll-to-assign) without rebuilding the board. C's look is a branding call.
