Holiday switch: where and how

The Holiday switch sits in the board toolbar between "New Employee" and "Filter & sort", styled as an on/off switch. The red dashed outline in each mock below marks where the control would go.

What the switch does (from the code)
  • It sets the date on screen to a non-working day for this board only. It is a property of the day, not of the view.
  • Switching it on clears that day's planned missions for everyone. It asks for confirmation first. Switching it off copies the latest working-day plan back.
  • It only shows on editable future dates (it is hidden on past dates and today).
  • Thai | English only changes which names you see. It changes no data.

So the Holiday control belongs with the date, and it should look different from a harmless view preference. Making it look the same as Thai | English would make clearing a day look as safe as switching names.

Problem: it sits among the "create" buttons and filters, but it changes the whole day. A switch that looks like a view setting hides how much it does.

A · Day chip next to the date, in the top bar Recommended

The date already says which day you are on, so the day type goes right beside it: a small chip that reads Working day or, in amber, Holiday. Clicking it opens a 2-choice menu with what each choice does. It is visible in one glance next to the date, and it can't be flipped by accident.

C · Inside the date picker

You choose days in the date picker, and it already shows weekends and holidays in colour. The picker gets a "This day is a holiday" switch at the bottom, and the toolbar loses the control altogether. On the board, the day shows the HOLIDAY pill as it does today.

My recommendation

A, with C as the phone version. The day type sits next to the date it describes, the toolbar drops a control, and the menu says what each choice does. I'd keep it different from Thai | English on purpose, because one changes data and the other only changes what you see. If you'd rather keep it in the toolbar, B is the better way to do that than the current switch.
