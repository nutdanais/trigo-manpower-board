Mobile vs desktop: what to carry over

Real screenshots from the current build (desktop 1440 px, phone 390 px, same test data). The phone Board tab already matches the desktop's Signal look well, so it stays as it is. The gaps are on the other tabs (Overview, Manpower, Host), which still use an older phone layout. Below are 4 changes, ordered by impact. Nothing is implemented yet.

Must

1. Every tab gets the Board's header: page title on the left, date pill on the right.

Must

2. Stat tiles become the Board's summary card (one line, colour dots, segmented bar, tap to expand).

Should

3. One ⋯ button: Bulk edit, Export and Filters go inside it, as on Board.

Should

4. Quieter record cards: sentence-case labels like the desktop tables, no card inside a card, 4 key fields with the rest folded.

2 · Summary card instead of the stat grid

  • Desktop shows these counts as one row of tiles over a segmented bar. On the phone, Manpower and Host break them into an uneven 2-column grid (Total on its own line, left borders misaligned), which costs about 170 px before the first record.
  • Overview on the phone shows "Boards: 2 | Utilization: 57.14% | …" as plain text that wraps, with the Standby alert and Export stacked below it.
  • Reuse the Board's summary card: one headline number, coloured dots, the same segmented bar, tap to expand for the full breakdown and By area. Same parts as desktop, phone-sized.

Should

3 · One ⋯ button, one primary action

  • Board has a square ⋯ icon button. Manpower and Host have a wide "⋯ More" text button, plus Bulk edit and Export as loose outline buttons on a row of their own.
  • Desktop's rule is one filled main action, everything else quiet. On the phone: keep + New Employee / + Host filled, put Search and Filter as icon buttons next to the summary card, and move Bulk edit, Export, Thai / English into ⋯. The ⋯ button looks the same on every tab.
Should

4 · Quieter record cards (Manpower, Host)

  • The desktop tables use sentence-case headers in muted grey (Name, Contract type). The phone cards use UPPERCASE grey labels on all 10 fields, so one person takes a full screen.
  • Each card sits inside another white card (double border), and "SELECT ALL" is an uppercase grey strip.
  • Proposed: name and area chip on top, then Contract, Board and 30-day utilization, with the rest behind "More details". Sentence-case labels, one card level, and the Active toggle on the card's top row.
  • Small bug in passing: on Host cards, the divider under Note is shorter than the others.

Not carried over

Desktop things that should stay desktop-only

  • The navy top bar with the lime line. On the phone, the navy bottom bar already carries the brand. A navy header too would make the screen heavy and take back the space you liked saving.
  • Side people panel. The drawer is the right phone form.
  • Full tables (By board, Engineer workload). They already turn into cards on the phone. Keep that.
