Modal style review

I opened all 26 modals in the app and checked each one. Every modal already has the new frame: a header bar, a footer bar, and a side panel for forms. What is still old is the inside of 11 of them (the bordered checkbox cards, .import-row, and a few loose lists), plus a Rename board box that still uses the browser's own pop-up. Below you can see the new style for each of those, starting with Add Mission.

1 · Add Mission (before → after)

This uses the same pattern as Hide/Unhide missions: a search box, filter chips, rows grouped in one box, columns for shift and time, engineer and crew, a tag on each row that says what Save will do, and a running total in the footer. Missions that are already on the forecast stay in the list but greyed out and locked.

3 · Review lists (Review changes, Merge decisions, Holds taken, Forecast)

These four lists use their own old styles: a group header with a left stripe, loose rows with a bottom border, and a plain list for the read-only Forecast viewer. In the new style they use the same grouped box, and the change type (Add, Move, Remove) moves into the tag on the right, so it looks like Hide/Unhide.
